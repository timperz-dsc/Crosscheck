# profiles/

Aircraft profiles describing the controls to sync. One YAML file per aircraft, in Crosscheck's own format (see [SCHEMA.md](SCHEMA.md)), with a `class:` per entry. Editor validation: [schema/profile.schema.json](schema/profile.schema.json).

- `fenix-a320/profile.yaml` – the Fenix A320 profile
- `fenix-a320/scan/` – raw L: var scan of Fenix 3.0
